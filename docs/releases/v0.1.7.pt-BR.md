# Twitchterino 0.1.7

- Mostra a versão atual no título da janela.
- Move os controles de conexão para os quatro cartões de conta: perfis conectados têm uma engrenagem com **Desconectar** e slots vazios mostram **Adicionar conta**.
- Desconecta somente o perfil escolhido, sem trocar a conta exibida nem abrir a janela de login. As outras contas continuam coletando.
- Remove o botão **Juntar pontos**: a coleta inicia automaticamente ao abrir o app com uma conta conectada, inclusive para perfis que estavam pausados.
- Preserva o foco dos menus durante atualizações e impede que o painel de bônus cubra os controles de conta em janelas menores.

Windows x64, instalador NSIS. Os perfis e as demais preferências existentes são preservados; sessões expiradas podem solicitar login novamente.
